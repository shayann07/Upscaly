## Data Flow

1. **Input Selection**: User drops or selects image/video → resolution metadata & thumbnail generated → state transitions to `FileSelected`.
2. **Pre-flight Check**: GPU availability, VRAM estimate, and target disk space are checked.
3. **Execution**: User triggers upscale → `start_upscale` command validates parameters → spawns sidecar binary (`realesrgan-ncnn-vulkan.exe`) bound under Windows Job Object → streams stderr progress events (`job-status-changed`) to frontend.
4. **Completion**: Processing reaches 100% → output file finalized → temporary video frames cleaned up via RAII guards → interactive before/after comparison slider rendered.
