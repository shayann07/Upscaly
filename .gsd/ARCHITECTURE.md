## Data Flow

1. **Input Selection**: User drops or selects image/video → resolution metadata & thumbnail generated → state moves to `FileSelected`.
2. **Execution**: User triggers upscale → `start_upscale` command validates storage/resources → spawns sidecar under Windows Job Object → streams stderr progress events to frontend (`job-status-changed`).
3. **Completion**: Processing reaches 100% → output file finalized → temporary frames cleaned up (RAII guard) → before/after slider rendered with hardware acceleration.
