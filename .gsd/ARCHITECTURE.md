## Data Flow

1. **Media Ingestion**:
   - Drag & drop into `StudioCanvas.tsx` / `DropZone.tsx` or Native File Picker via `commands/files.rs` (`pick_files` / `pick_folder`).
   - Image/video metadata extracted (dimensions, duration, FPS) and loaded into `useMediaSelection` or `useBatchSetup`.

2. **Job Dispatch**:
   - User triggers upscale $\rightarrow$ `useStudioActions.ts` invokes `run_upscale` IPC command $\rightarrow$ `commands/upscale.rs` enqueues job into `job_queue.rs`.
   - Output path reserved with collision protection via `output_paths.rs`.

3. **Inference Execution**:
   - **Image Job**: `job_queue.rs` launches `realesrgan-ncnn-vulkan.exe` inside Windows `JobObjects` container with calculated tile size.
   - **Video Job**: `video_pipeline::phases` extracts frames via `ffmpeg.exe`, executes sequence upscaling via NCNN sidecar, and `encoder.rs` remuxes audio and frames back into container.

4. **Telemetry & Progress**:
   - Sidecar stdout parsed $\rightarrow$ progress, ETA, and FPS emitted via `job-status-changed` Tauri events $\rightarrow$ `useJobEvents.ts` updates `ProgressOverlay.tsx`.

5. **Completion & Inspection**:
   - Output file written $\rightarrow$ Windows JobObject cleans up child processes and VRAM $\rightarrow$ Completion chime played $\rightarrow$ `CompletionCard.tsx` opens output with native Explorer integration.
