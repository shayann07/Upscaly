# Plan 7.3 Summary: Extract Upscale Commands & Refactor Parameter Signature

## Overview
Plan 7.3 extracted upscale invocation and job cancellation handlers into `src-tauri/src/commands/upscale.rs` and refactored internal helper parameters to consume `UpscaleRequest`.

## Key Changes
- Created `src-tauri/src/commands/upscale.rs` (`run_upscale`, `upscale_image`, `cancel_upscale`, `enqueue_job`, `cancel_active_job`).
- Refactored `upscale_image` helper function signature from 9 positional arguments to 2 (`app_handle: tauri::AppHandle`, `request: UpscaleRequest`).
- Refactored `upscale_image` helper function to be synchronous to resolve `clippy::unused_async`.
- Updated `src-tauri/src/lib.rs` invocation handler composition using `commands::<domain>::<cmd>`.
