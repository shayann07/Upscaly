# Milestone Summary: v2.0-win-gpu-reliability

## Completed: 2026-08-05

## Milestone Objective
Refactor the app around a reliable, event-driven job runtime while preserving the current inference contract on Windows x64 Vulkan devices.

---

## Deliverables & Key Accomplishments
- ✅ **Phase 1: Establish Regression & Benchmark Evidence First**
  - Created `tests/fixtures/corpus_manifest.json` defining image/video baseline fixtures and RGBA pixel hash standards.
  - Implemented `npm.cmd run benchmark` Node runner.
  - Defined `ProcessRunner` trait with `StdProcessRunner` and `MockProcessRunner` in `src-tauri/src/process_runner.rs`.
  - Repaired and expanded frontend Vitest test suite (`17/17` passing).

- ✅ **Phase 2: Replace Queue with Cancellable Race-Free Job Runtime**
  - Added client-generated `job_id` (`crypto.randomUUID()`) to IPC calls in `lib.rs` and `App.tsx`.
  - Refactored backend queue to `VecDeque<Job>` with `ActiveJobRegistry` (`HashMap<String, JobControl>`).
  - Added atomic `stop_monitor` signal to video frame monitoring thread to prevent deadlocks.
  - Implemented `reserve_output_path` backend module for filename collision protection (`_upscaled_4x (1).png`).

- ✅ **Phase 3: Make GPU Discovery Truthful & Resilient**
  - Parsed NCNN probe into structured `GpuDevice` capabilities (`fp16_storage`, `fp16_arithmetic`, `compute_queue_count`).
  - Implemented 24h `GpuCacheEnvelope` with sidecar SHA-256 binary hash checking.
  - Returned explicit empty list `[]` when 0 Vulkan GPUs exist (no fake Auto GPU ID 0).
  - Disabled upscale CTA buttons when `gpus.length === 0` and popped driver setup guidance toasts.

- ✅ **Phase 4: Package Self-Contained LGPL Windows Video Runtime**
  - Created `docs/THIRD_PARTY_NOTICES.md` documenting pinned LGPL FFmpeg build flags (`--enable-version3 --disable-gpl`) and excluding GPL `libx264`.
  - Registered `ffmpeg` and `ffprobe` target-triple sidecars in `tauri.conf.json`.
  - Implemented `get_system_diagnostics` IPC command in `lib.rs`.
  - Implemented vendor H.264 encoder search order (`h264_nvenc` → `h264_qsv` → `h264_amf` → `h264_mf`).
  - Implemented `-c:a copy` with AAC 192kbps stereo fallback; implemented VFR detection with FFprobe and explicit early error rejection.

- ✅ **Phase 5: Apply Only Output-Preserving GPU Optimizations**
  - Implemented `compute_workload_threads` in `job_queue.rs` (`4:4:4` for <=4MP, `2:2:2` for >=12MP / video, `1:2:2` for standard workloads).
  - Implemented `normalize_tile_size` in `job_queue.rs` (`0` auto default; clamps custom values to 32-1024 multiples of 32).
  - Preserved exact model, scale factor, and TTA (`-x`) flag across all jobs.

- ✅ **Phase 6: Final Verification & Release Criteria**
  - Automated test matrix execution: `cargo test` (11/11 passed), `npm.cmd run test` (17/17 passed), `npm.cmd run benchmark` (passed).
  - Generated `phase-6-VERIFICATION.md`.
